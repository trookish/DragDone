# IDEA.md — DragDone

## Project Name
**DragDone**

## One-Liner
A lightweight Windows utility that turns any file drag into instant useful actions — convert, crop, compress, and more — without opening other apps.

## Core Idea
Most everyday file tasks force users to open heavy applications, dig through menus, or use multiple tools.  
DragDone eliminates that friction with a single, universal interaction:

> **Drag a file → Get a smart radial menu → Done.**

The entire experience is built around the philosophy:  
**“Drag • Press • Done”**

## Key Features
- **Contextual Radial Menu**  
  Drag any file (or multiple files) and a clean pie/radial menu appears with relevant actions based on file type.

- **Smart File Actions**
  - Format conversion (PDF ↔ Image, Video ↔ Audio, etc.)
  - Image crop, resize, and rotate
  - Compress / optimize files
  - Extract audio from video
  - Quick share (Nearby sharing or similar)
  - Other common operations (rename, move, etc.)

- **Keyboard Modifiers**
  - `Ctrl`, `Shift`, and `Alt` unlock different menus or advanced actions while dragging.

- **In-Place Experience**
  Everything happens directly on the Desktop or in File Explorer. No windows to manage, no apps to launch.

- **Offline First**
  Fully functional without an internet connection.

- **Arabic & RTL Support**
  Native right-to-left interface and full Arabic language support from day one.

## Target Platform
- Windows 10 / Windows 11
- Designed to feel like a native modern Windows power-user tool (Fluent Design inspired)

## Design Principles
- Invisible until needed
- Extremely fast and lightweight
- Zero learning curve for basic use
- Minimal UI chrome
- Keyboard + mouse first (great for power users)

## Why It Matters
File management is one of the most frequent but still clunky activities on desktop.  
DragDone aims to make the most common file operations feel as natural and instant as copying a file.

## Future Possibilities (Out of Scope for MVP)
- Custom action plugins
- Batch processing presets
- Integration with cloud services
- Cross-platform version (macOS / Linux)
